Datenschutzerklärung

Dieser Discord-Bot speichert ausschließlich Daten, die für den Betrieb erforderlich sind.

Gespeicherte Daten

  • Discord User IDs
  • Discord Server IDs
  • Ticketdaten und Einstellungen

Zweck

Die Daten werden zur Bereitstellung der Bot-Funktionen verwendet.

Löschung

Auf Anfrage können gespeicherte Daten gelöscht werden.
